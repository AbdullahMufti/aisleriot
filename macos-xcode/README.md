# Aisleriot macOS (Xcode) port

This directory is a starting point for a native macOS port of Aisleriot, built with
Xcode/Swift/SpriteKit. It currently sets up the project scaffolding only (no game
logic ported yet) and lives alongside the original GTK/Guile source in this fork.

## Building

Open `aisleriot.xcodeproj` in Xcode and run the `aisleriot` scheme (macOS target).
